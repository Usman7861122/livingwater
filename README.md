# Living Water Clinic website

Astro 7 + React islands + Tailwind v4 + Framer Motion.

```bash
npm install --legacy-peer-deps
npm run dev      # local dev server
npm run build    # static build to dist/
```

Before launch: set `site` in `astro.config.mjs` to the real domain, and connect the contact form (`src/components/islands/ContactForm.tsx`).
